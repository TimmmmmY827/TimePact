# Surface brief: TimePact desktop shell

## Composition

- Default window: 920×720; supported compact floor: 760×600.
- Fixed 64px left rail with icon-only destinations: tasks, focus, statistics, settings.
- Main content uses a restrained maximum width and compact vertical rhythm.
- Home places the task composer first, a small focus launcher second, then grouped active tasks.

## Task row

- Thin colored progress line sits directly above each row.
- Red/orange indicates waiting or urgent, blue indicates active timing, neutral indicates unscheduled.
- Row keeps title and primary time state dominant; secondary metadata and actions remain visually quiet.
- Groups: requires attention, in progress, unscheduled.

## Visual system

- System UI sans-serif; tabular numerals for time.
- Cool neutral canvas, white/dark surfaces, blue primary accent, restrained borders and shadows.
- Light, dark, and system modes share the same semantic token names.
- Focus visibility, keyboard operation, reduced motion, and 760×600 reflow are required.
