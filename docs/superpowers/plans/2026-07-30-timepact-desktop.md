# TimePact 桌面首版实施计划

## 目标

交付一个可安装的 Windows 本地桌面应用，实现待办计时、到期确认、循环专注、归档统计、备份恢复和托盘运行。

## 实施分层

1. **领域模型**：在 TypeScript 和 Rust 中定义 Task、TaskTimer、FocusSession、AppSettings；用原始截止时间与当前提醒时间分离保证统计语义。
2. **本地持久化**：SQLite 保存任务、执行事件与应用状态；启动时迁移数据库并启用 WAL。
3. **计时运行时**：Vue 负责即时交互显示，Rust 后台线程负责 Deadline/倒计时到期、休眠补偿、提醒窗口与每日快照。
4. **桌面集成**：独立提醒窗口、系统托盘、单实例、开机启动、窗口状态恢复和 NSIS 当前用户安装。
5. **数据可携带性**：JSON 备份/恢复、7 日自动快照、历史 CSV 导出。
6. **界面**：64px 图标导航、紧凑单列任务页、首页专注入口、卡片顶端彩色时间进度线、浅色/深色/系统主题。

## 验证

- Vitest 覆盖创建、排序、分组和进度计算。
- `vue-tsc` 与 Vite 生产构建验证前端。
- `cargo check` 验证 Rust API、安全权限和数据库代码。
- Tauri NSIS 构建验证安装包；在 760×600 与 920×720 两档检查紧凑布局。
- 人工验证：创建未安排/Deadline/倒计时待办，启动/暂停/延期/完成，提醒窗口集中处理，专注轮次，JSON 恢复和 CSV 导出。
